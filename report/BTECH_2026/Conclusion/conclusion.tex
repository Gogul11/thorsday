\chapter{\uppercase{Conclusion and Future Work}}
\label{chap:conclusion}

AgentOS integrates planning, dependency-aware execution, context paging, scheduling, resource admission, bounded code execution, model routing, and frontend observability into a unified multi-agent runtime. The implemented system connects the frontend, gateway, kernel, data stores, event transport, specialised agents, and model providers into one observable execution pipeline. Evaluation recorded 98.0\% retrieval success on the synthetic context set, 35.0\% on the LoCoMo pilot, a 76.0\% exact tool-set rate across 50 planner trials, and high-priority queue-wait $P_{95}$ reductions of approximately 68\% in steady state and 78\% under contention compared with FIFO. These results demonstrate the prototype's intended behaviour within the scope of the study.

Future work will extend AgentOS beyond its current prototype boundaries by improving durable recovery, execution checkpoints, and restoration of interrupted coroutines. It will also add explicit permission policies, stronger sandbox isolation, and more complete hybrid local/cloud model routing. Further evaluation should use production-like traces, non-stubbed persistence, varied provider conditions, held-out conversations, paraphrased tasks, answer-level judging, and larger repeated trials. Additional tool-use scenarios and event-triggered workflows can provide a broader assessment of the architecture's generalisability and practical readiness.
